# Heels Catalog (Static)

This folder is a static site (HTML/CSS/JS) + images for browsing with filters.

## Run locally

- Open `index.html` directly, or
- Use `tools/serve.ps1` (PowerShell) to start a local server.

## Publish to GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repo settings, enable **Pages** and select:
   - **Deploy from a branch**
   - Branch: `main` (or the branch you pushed)
   - Folder: `/ (root)`

> Note: If your images include adult/explicit content, please double-check GitHub’s policies before enabling public Pages.
